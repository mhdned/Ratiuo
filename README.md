# Ratiuo

Ratiuo is a small personal project built to learn and practice **Vue.js**.

Currently, Ratiuo is a static application designed to help interviewers collect information and answers from developers during technical interviews.

## Overview

The main technology behind Ratiuo is **Vue.js**. The current version is intentionally simple and frontend-focused.

In the future, I may add a minimal backend using **PHP**. This is also a way for me to get back into PHP after spending a lot of time away from it.
